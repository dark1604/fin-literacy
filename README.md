# 💰 Інтерактивний підручник: Підприємництво і фінансова грамотність (8–9 класи)

Інтерактивний освітній вебзастосунок для учнів **8–9 класів** із курсу **«Підприємництво і фінансова грамотність»**, що об'єднує дві авторські лінійки підручників у сучасному гейміфікованому інтерфейсі.

🔗 **Онлайн-версія (GitHub Pages):** https://dark1604.github.io/fin-literacy/

---

## ✨ Можливості
- **Дві авторські лінійки на вибір:**
  - **О. В. Пластун та ін.** (`plastun.html`) — 8 клас (13 параграфів, 3 практичні роботи, підсумковий тест на 23 питання) та 9 клас (18 параграфів, 6 практичних робіт).
  - **А. Я. Кузнєцова та ін. (УОВЦ «Оріон»)** (`kuzniecova.html`) — 8 клас (7 тем, 15 «Досвідів») та 9 клас (9 тем, 30 «Досвідів») з тематичною палітрою.
- **Зручна навігація:** перемикання за автором або за класом прямо зі стартової сторінки (`index.html`), а також швидкий перехід між лінійками.
- **Інтерактивні завдання:** вбудовані таблиці, форми, практичні роботи, кейси та тести для самоперевірки.
- **Без збірки та серверів:** чистий `HTML + CSS + JavaScript`, працює миттєво у будь-якому сучасному браузері.

---

## 📂 Структура проєкту

```text

├── data-grade9.js         # Контент 9 класу (О. Пластун)
├── data-kuzniecova-8.js   # Контент 8 класу (А. Кузнєцова)
└── data-kuzniecova-9.js   # Контент 9 класу (А. Кузнєцова)
```

## 🚀 Публікація на GitHub Pages
1. Завантажте файли у гілку `main` репозиторію.
2. У налаштуваннях репозиторію перейдіть у **Settings → Pages**.
3. Оберіть джерело **Deploy from a branch** → гілка `main` → папка `/ (root)` і збережіть.
